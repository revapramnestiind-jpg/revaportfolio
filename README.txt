REVA PERSONAL PORTFOLIO

Files:
- index.html   -> Home
- about.html   -> About + list + table
- project.html -> Projects + form/input/button
- style.css    -> External CSS
- assets/profile.svg -> Temporary profile image

Open index.html in Google Chrome to view the website.

The project uses only HTML5 + CSS (no Bootstrap/framework).
It includes semantic HTML, table, image + alt, links, list, form,
input, button, inline/internal/external CSS, Flexbox, and media query.
